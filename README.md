# 🥗 FreshTrack – Smart Food Expiry & Waste Tracker

**Track Freshness. Reduce Waste. Save More.**

FreshTrack is a smart food management web application designed to help users organize their food inventory, monitor expiry dates, reduce food waste, and make smarter kitchen decisions.

The application combines food inventory management, automated expiry alerts, recipe recommendations, barcode scanning, nutrition insights, and shopping suggestions in one platform.

## 🚀 Features

- **User Authentication:** Login and signup functionality.
- **Food Inventory Management:** Add, update, delete, and manage food items.
- **Expiry Date Tracking:** Monitor food items approaching or past their expiry dates.
- **Smart Notifications:** Receive alerts about expiring and expired food.
- **Recipe Recommendations:** Get recipe suggestions based on available inventory, prioritizing food nearing expiry.
- **Barcode Scanner:** Scan product barcodes to retrieve food information.
- **Nutrition Insights:** Search food products and explore nutritional information.
- **Smart Shopping List:** Manage shopping items and receive purchase recommendations.
- **Food Waste Analytics:** Track food consumption, waste, and estimated savings.
- **Food Donation Tracker:** Record and manage food donations.
- **Dark/Light Theme:** Switch between themes for a comfortable user experience.

## ⚙️ Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/FreshTrack-Smart-Food-Tracker.git
   ```

2. Open the project folder:

   ```bash
   cd FreshTrack-Smart-Food-Tracker
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

4. Allow camera access when using the barcode scanner.

## 🎯 Project Objective

The main objective of FreshTrack is to encourage responsible food consumption by helping users track food freshness, use available ingredients efficiently, avoid unnecessary purchases, and minimize household food waste.
